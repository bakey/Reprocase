# Phase 1 / M0 — Contracts and run skeleton

M0 freezes the smallest useful contracts before Docker, real agents, or deterministic state
graders add more failure modes.

## Acceptance criteria

- [x] Strict EvalCase v0 and Environment v0 models.
- [x] Precise schema and reference-path validation.
- [x] Deterministic digest over normalized case and environment content.
- [x] Explicit run lifecycle and stable failure codes.
- [x] Atomic `manifest.json` and `result.json` writes.
- [x] Append-only, sequenced `events.jsonl`.
- [x] Fake Environment, Agent, and Grader end-to-end run.
- [x] Interrupted/internal failures preserve a diagnosable run record after storage exists.
- [x] Committed JSON Schemas verified by tests.
- [x] GitHub CI tests Python 3.12/3.13 and enforces coverage, formatting, lint, typing, and Schema checks.

## M0 execution semantics

The fake components exercise orchestration contracts only:

```text
validate
  -> prepare fake environment
  -> start
  -> restore
  -> healthcheck
  -> capture fake initial state
  -> execute fake agent
  -> capture fake final state
  -> execute fake graders
  -> teardown
  -> write result
```

The manifest declares `reproducibility_level: R0`. M1 will introduce Docker Compose restore and
state digest stability, at which point real environment runs can claim R1.

## Verdict rules

- Environment, grader, or runner errors produce `INVALID`.
- Agent execution or evaluation failures produce `FAIL`.
- A run without failures and with all graders passing produces `PASS`.

Case/schema errors are rejected before a run directory is created and use CLI exit code 2.

## Design constraints carried into later milestones

- Input and output models reject unknown fields.
- Schema versions are explicit string literals.
- Machine consumers use stable enum values, not human messages.
- Events are ordered by per-run `sequence`, not wall-clock timestamps.
- Atomic result writes prevent partially valid JSON from looking complete.
- Fake implementations stay visibly named and cannot be mistaken for production drivers.
